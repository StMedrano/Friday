# Trusted project/task vertical slice

The operator requested one local vertical slice using the approved Postgres architecture. This extends the prior headless boundary only for project enumeration and task list/create, behind verified Access identity and a server-injected access service. No production bootstrap, environment switch, actual identity, private endpoint, worker or credentials are configured.

## Smallest implementation

1. Reuse `friday_projects` as the trusted provisioned catalog, queried server-side with select=id,name and limit=51; reject malformed, duplicate or >50 records rather than authorizing a partial catalog. Never provision projects through the browser. Validate owner identity before catalog reads; rebuild explicit owner bindings from the current catalog for every task operation. No group/operator/model grants, agents or memory scopes.
2. Reuse WorkService validation/fingerprints and the PostgREST repository. Expose only GET /api/projects and GET/POST /api/projects/:id/tasks. Require live mode, signed Access identity and explicit injected service; POST additionally requires exact Origin and JSON. Fail closed by default. Return only normalized task fields, never principals, fingerprints, keys or storage errors. Preserve idempotent request IDs across unchanged retries. No status update, claim, executor, attachment or memory endpoint.
3. Add the Tasks workspace using existing navigation/theme. Loading, denied, unavailable, malformed, empty and saved states are distinct. Preserve drafts on write failure; show no optimistic success. Cancel pending reads, clear cross-project results and disable project selection during writes. Add component/HTTP/domain tests, actual built-browser regressions and disposable SQL tests. No migration: existing tables/FK/unique/check constraints suffice.
4. Full tests/build, pinned-dependency audit, browser tests and exact-head CI (including existing isolated SQL/container/scanner gates). Local Docker/make availability is independently checked and unavailable gates explicitly reported.
